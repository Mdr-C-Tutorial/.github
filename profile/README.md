# Mdr-C-Tutorial

这里是 mdr 的 C 语言教程的 GitHub 组织主页。

## 概述

本教程至少包含以下内容：

+ 讲义
+ 视频教程
+ 官方网站主站
+ 官方论坛
+ 官方代码评测平台

以上所有内容均开源免费。任何组织或个人均可引用本教程任何内容，除非将其用于商业用途。

## 仓库

本组织内至少包含以下仓库：

+ `C` - 讲义，部署于 GitHub Pages。mdr 喜欢将其叫做「梦猫大典」。
+ `WebSite` - 官网前端。
+ `BackEnd` - 官网后端。
